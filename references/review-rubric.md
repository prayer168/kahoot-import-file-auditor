# 逐題審查規準

每個結論引用原題文字、選項、儲存格或來源；避免只寫「符合／不符合」。

## 課綱與素養

把學習內容（學什麼）、學習表現（做什麼）與核心素養分開核對。正式課綱常以學習階段描述，不能由階段直接推定某年級某學期已教過；版本與進度不明時保留待確認。國小低年級不直接套用中高年級自然科學領域指標。

素養程度可用下列分析標記，這是本技能的描述工具，不是教育部評分標準：

| 標記 | 題目實際要求 |
| --- | --- |
| 記憶辨識 | 回憶名稱、定義或孤立事實 |
| 概念理解／直接應用 | 解釋概念或在熟悉條件下運用 |
| 情境資訊運用 | 需讀取、選取或比較題中資訊才能作答 |
| 整合推理／探究決策 | 結合證據、控制條件或替代方案進行推論與決策 |

刪掉故事仍能用相同資訊及方法作答，可能只是情境包裝。短題也可能有良好推理要求，長題不必然更具素養。難度與認知層次分開評估。選擇題可測推理判斷，但不足以證明學生實際具備實作、合作或態度表現。

## 答案與科學

- 求解前不以原答案為前提。檢查所有選項，不只替標示正解找支持。
- 單選需唯一且明確可辯護。多選需所有成立選項均列入答案；不要僅由原答案編號個數推斷命題者題型。
- 檢查不同合理解讀、隱含條件、時間／地點限制、尺度、常態與例外。指出小學階段可接受的簡化及不能省略的關鍵條件。
- 因果不能僅由相關推出；觀察與推論分開；實驗須考慮操作變因、應變變因、控制條件和測量限制。
- 缺圖題、引用未提供資料的題目：保留原題，不憑空生成圖表內容作為解答。
- 計算題保留算式、單位及四捨五入條件；核對匯入答案編號與核定答案文字一致。

## 迷思與誘答

每個錯誤選項記錄：可能錯誤理解 → 學生為何可能選它 → 題中或科學依據如何排除 → 預期誘答性（合理／偏弱／無法判定）。

可辨識的錯誤包括：把外觀當本質、混淆相關與因果、忽略控制條件、把個案過度概括、混淆方向／單位、程序操作錯誤。這些僅是分析角度，不可硬套成實證常見迷思。粗心或語文誤讀不必然是概念迷思。

檢查選項長度、文法、科學名詞密度與語氣洩題；選項是否重疊、同義、相互包含或跨不同判準。「以上皆是／皆非」及絕對字眼依語境分析，不因字眼出現就一律判錯。不要把錯誤選項改成荒謬選項來維持答案唯一。

沒有作答資料時不提供實測答對率、鑑別度或誘答選擇率。若有資料，另外交代樣本、缺失值、計算方法與適用限制；不能由一次錯選直接診斷某學生固定持有某迷思。

## 年段與語言

以臺灣繁體中文教學語境判斷，檢查超出先備知識的抽象詞、成人情境、長句、多層條件、否定及指涉。必要專有名詞可保留並搭配簡短說明，避免過度口語化造成科學錯誤。

提供「原詞／原句 → 建議用詞／改寫 → 原因」；區分課程必要術語、可由上下文理解的詞及不必要的難詞。年級未知就標年段待確認，不把可讀性公式當成年級適切性的證據。

同時評估閱讀、看圖與推理所需時間；不能所有題一律使用固定秒數。是非題若以兩個選項存在，需檢查科學敘述與正解，勿強行補成四選項。

## 分級例子

| 情況 | 判定 |
| --- | --- |
| 四選一中兩個答案均符合題幹 | A：修改題幹條件或選項，重驗全部選項 |
| 題目依賴未附的圖表 | A：關鍵資訊缺漏；答案另標無法判定 |
| 生活情境只是裝飾，但本題本來是概念複習 | 說明其認知要求，不自動判不合格 |
| 宣稱為迷思診斷題，三個錯誤選項都可憑常識排除 | B：誘答診斷功能不足 |
| 未提供年級與版本 | 年段與進度待確認，繼續答案查證 |
| 題幹稍冗長但意思清楚 | C；若已實質阻礙作答，升 B |
